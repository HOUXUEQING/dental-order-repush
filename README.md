# 齿科服务 · 异常订单（订单状态补推）

在线原型：https://houxueqing.github.io/dental-order-repush/
PRD 下载：https://houxueqing.github.io/dental-order-repush/PRD.docx

## 菜单

- 一级菜单：齿科服务
- 二级菜单：异常订单

## 原型包含

1. 异常订单列表
   - 筛选：订单编号、服务商（康恩斯瑞 / 瑞尔）、预约人姓名、手机号、下单时间
   - 列表：壹账通单号、业务公司、业务公司单号、服务商、服务商单号、预约人姓名、手机号、预约门店、最新订单状态、最早未成功订单状态、未成功条数、最近失败原因、失败时间、操作
2. 订单流转详情：序号、订单状态、预约门店、预约时间、状态变更时间、推送结果，头部含预约人姓名、手机号、下单时间
3. 补推弹窗：默认全选，可单推，必填原因与备注
4. 报文详情：状态变更时间、推送时间、失败原因、推送报文快照

## 脱敏规则

- 姓名：保留首字，其余用 * 代替（张*、欧***）
- 手机号：保留前 3 位与后 4 位（138****5678）

## 状态说明

共 14 个订单状态：2 个内部状态（待确认、取消审核中）不推送；7 个中间态；5 个终态。
推送结果仅区分成功与失败，超时与无回执均按失败处理。
